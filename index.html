🐍 App de escritorio (Python 3.14)

Visor nativo con Tkinter. Sin dependencias externas, sin pip install.

  1. 1Instala Python 3.14 desde python.org.
  2. 2Guarda el archivo view_url.py (ver abajo).
  3. 3Abre IDLE → File → Open….
  4. 4Pulsa F5 para ejecutar.
# Clona el repositorio y ejecuta:
git clone https://github.com/TU_USUARIO/view-url.git
cd view-url
python view_url.py

🌐 Demo web (esta página)

Funciona directamente en el navegador. Para saltar las restricciones CORS usa un proxy público.

  • AllOrigins — el más estable.
  • CodeTabs — buena velocidad.
  • corsproxy.io — alternativa.

Si un proxy falla, prueba con otro desde el selector.

# Cómo publicar esta página en GitHub Pages
1. Crea un repo nuevo en GitHub
2. Sube index.html a la raíz
3. Settings → Pages → Branch: main / (root)
4. Espera ~1 min. Tu URL: https://TU_USUARIO.github.io/view-url/
