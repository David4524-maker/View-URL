# View URL

View URL es una app para ver el código de las `paginas webs`

---

## View URL de Python 3.14

Esta version que es la original puede mostrar el codigo de cualquier pagina web (Ej: https://jspaint.app) 

## Caracteristicas (Original)

- Muestra cualquier código de cualquier pagina web

- Copiar, Guardar y Abrir Web

- Modo oscuro

- Sin `pip install`

---

## View URL DEMO (HTML)

Esta versión es una DEMO de View URL, ósea si muestra código de paginas web pero las paginas grandes (como YouTube, Facebook) lo bloquearan mediante CORS estrictos

## Caracteristicas (Demo)

- Modo Oscuro

- Ajustar, copiar y descargar

- URL de GitHub Pages
